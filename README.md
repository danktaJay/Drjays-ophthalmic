# Dr Jay's Ophthalmic Patient Appreciation

Upload these files to a public GitHub repository and enable GitHub Pages.

- `/` = patient appreciation card
- `/generator.html` = Patient Appreciation Generator

The generator creates a link containing the first name and appreciation text, so no database or paid backend is required. Do not put diagnoses, prescriptions, addresses, dates of birth or other clinical information into the link. A unique URL is not password protection.

GitHub: Settings → Pages → Deploy from branch → main → /(root).
